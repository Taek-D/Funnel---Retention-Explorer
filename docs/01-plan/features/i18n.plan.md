# Plan: i18n — Internationalization (Phase 9)

## 1. Overview

FRE Analytics에 다국어(한국어/영어) 지원을 추가합니다.
현재 모든 UI 텍스트가 한국어로 하드코딩되어 있어 (55개 파일, ~722개 문자열),
국제 사용자를 위한 영어 지원이 불가능합니다.
react-i18next를 도입하여 번역 인프라를 구축하고, 전체 UI를 한/영 전환 가능하게 합니다.

## 2. Problem Statement

| 문제 | 현재 상태 | 목표 |
|------|----------|------|
| 다국어 지원 | 없음 (한국어 하드코딩) | 한국어 + 영어 |
| 번역 시스템 | 없음 | react-i18next 기반 |
| 언어 전환 UI | 없음 | 헤더/사이드바 언어 스위처 |
| 브라우저 언어 감지 | 없음 | navigator.language 기반 자동 감지 |
| SEO 다국어 | 없음 | lang 속성 동적 변경 + hreflang |
| 번역 파일 | 없음 | JSON namespace별 분리 |

## 3. Requirements

### I18N-1: i18next Infrastructure Setup
- `react-i18next`, `i18next`, `i18next-browser-languagedetector` 설치
- `lib/i18n.ts` 초기화 파일 생성 (languageDetector, fallbackLng: 'ko')
- `locales/ko/` 및 `locales/en/` 디렉토리 구조
- Namespace별 JSON 파일 분리 (common, pages, insights)
- `index.tsx`에서 i18n 초기화 import
- localStorage 기반 언어 설정 영속

### I18N-2: Common UI Strings (공통 컴포넌트)
- `locales/ko/common.json` / `locales/en/common.json`
- 대상 파일 (19개 컴포넌트):
  - Sidebar: 메뉴 라벨 7개 + aria-label + 툴팁
  - AppShell: 헤더 텍스트, 모바일 메뉴
  - Modal: "닫기" aria-label
  - Toast: "알림 닫기" aria-label
  - ErrorBoundary: "오류가 발생했습니다", "다시 시도", "페이지 새로고침"
  - PageLoader: "로딩 중..."
  - PlanBadge: "Pro", "Free", "업그레이드"
  - UserMenu: 메뉴 항목
  - SearchModal: 검색 관련 텍스트
  - UpgradeModal: Pro 업그레이드 관련 텍스트
  - SubscriptionStatus: 구독 상태 텍스트
  - BillingHistory: 결제 내역 텍스트
  - PastDueBanner: 결제 경고 텍스트
  - ShareButton: 공유 관련 텍스트
  - SaveAnalysisButton: 저장 관련 텍스트
  - AskAIPanel: AI 질문 관련 텍스트
  - NotificationPanel: 알림 텍스트
  - OnboardingTour: 투어 단계 텍스트
  - LandingHeader: 헤더 네비게이션 텍스트

### I18N-3: Page Strings (페이지)
- `locales/ko/pages.json` / `locales/en/pages.json`
- 대상 페이지 (17개):
  - Dashboard: 빈 상태 CTA, 카드 제목, 통계 라벨
  - DataImport: CSV 업로드 안내, 컬럼 매핑 라벨, 샘플 데이터 카드
  - FunnelAnalysis: 분석 컨트롤, 차트 라벨, 템플릿 이름
  - RetentionAnalysis: 코호트 설정, 차트 라벨
  - SegmentComparison: 세그먼트 설정, 비교 라벨
  - Insights: 인사이트 카드 제목, 필터 라벨
  - LandingPage: 히어로 텍스트, 기능 설명, CTA
  - LoginPage / SignupPage: 폼 라벨, 버튼, 안내 텍스트
  - PricingPage: 요금제 비교, 기능 목록
  - SubscriptionPage: 구독 관리 UI
  - BillingSuccessPage: 결제 완료 안내
  - SharedReport: 공유 리포트 텍스트
  - NotFoundPage: 404 에러 텍스트
- 대상 제외 (한국어 전용):
  - PrivacyPage (개인정보처리방침) — 법적 문서
  - TermsPage (이용약관) — 법적 문서

### I18N-4: Dynamic Content Strings (동적 콘텐츠)
- `locales/ko/insights.json` / `locales/en/insights.json`
- 대상 모듈:
  - `insightsEngine.ts`: 인사이트 타이틀/본문/추천 (~67개 문자열)
  - `csvParser.ts`: 에러/경고 메시지
  - `formatters.ts`: 날짜/숫자 포맷 (Intl API 활용)
  - `planManager.ts`: 플랜 관련 메시지
- 대상 훅 (8개):
  - useCSVUpload: toast 메시지 (~29개)
  - useFunnelAnalysis: toast/알림 메시지
  - useRetentionAnalysis: toast 메시지
  - useSegmentComparison: toast 메시지
  - useAIInsights: toast 메시지
  - useExportReport: toast 메시지
  - useSavedAnalyses: toast 메시지
  - useOnboardingTour: 투어 텍스트

### I18N-5: Language Switcher UI
- 사이드바 하단 또는 AppShell 헤더에 언어 전환 버튼
- 🇰🇷 / 🇺🇸 플래그 아이콘 또는 "KO" / "EN" 텍스트 토글
- `i18n.changeLanguage()` 호출
- localStorage에 선택 저장 (`fre-language`)
- 변경 시 `document.documentElement.lang` 동적 업데이트

### I18N-6: SEO & Meta Internationalization
- `index.html`: `lang` 속성 동적 변경 (i18n 언어에 따라)
- `og:locale` 동적 변경 (`ko_KR` / `en_US`)
- `<title>` 및 `<meta description>` 동적 변경
- `hreflang` alternate 링크 추가

## 4. Scope

### In Scope
- react-i18next 인프라 구축 (설정, 네임스페이스, 감지기)
- 한국어 번역 파일 생성 (기존 하드코딩 문자열 추출)
- 영어 번역 파일 생성
- 전체 컴포넌트/페이지/훅 `t()` 함수 적용
- 언어 전환 UI
- SEO meta 태그 다국어

### Out of Scope
- 3개 이상 언어 지원 (한/영 2개만)
- 법적 문서 번역 (PrivacyPage, TermsPage — 한국어 전용 유지)
- RTL 레이아웃 지원
- 서버사이드 번역 (Edge Function 메시지)
- 번역 관리 도구 (Crowdin, Lokalise 등)
- 날짜/시간 라이브러리 (date-fns/dayjs — Intl API로 충분)

## 5. Success Criteria

| Metric | Target |
|--------|--------|
| 번역 커버리지 | 95%+ (법적 페이지 제외) |
| 지원 언어 | 한국어 + 영어 |
| 번역 파일 | 3 네임스페이스 x 2 언어 = 6 파일 |
| 기존 테스트 | 208/208 유지 |
| 빌드 | 깨지지 않음 |
| 번들 영향 | < 30KB 추가 |
| 언어 전환 | < 100ms 반응 시간 |

## 6. Implementation Order

1. I18N-1: Infrastructure Setup (i18next, config, locales directory)

3. I18N-3: Page Strings (17개 페이지 — 법적 페이지 제외)
4. I18N-4: Dynamic Content (insightsEngine, hooks toast messages)
5. I18N-5: Language Switcher UI
6. I18N-6: SEO & Meta Internationalization

## 8. Risk Assessment

| Risk | Impact | Mitigation |
|------|--------|------------|
| 대규모 코드 변경 (~55 파일) | High | 네임스페이스별 단계적 적용 |
| 기존 테스트 깨짐 | High | t() mock 추가 to setupTests |
| 번역 누락 | Medium | fallbackLng: 'ko'로 누락 시 한국어 표시 |
| 번들 크기 증가 | Low | i18next는 경량 (~15KB gzipped) |
| insightsEngine 보간 복잡도 | Medium | ICU MessageFormat 또는 template literal 패턴 |
| SEO 영향 | Low | hreflang + og:locale로 검색엔진 대응 |
